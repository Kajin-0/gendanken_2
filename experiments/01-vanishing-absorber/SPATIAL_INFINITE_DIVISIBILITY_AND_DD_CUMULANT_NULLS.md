## 1. The simplest spatial-regeneration statement

Suppose a carrier moves through a scalar, homogeneous one-dimensional transport region and the coordinate itself is a complete regenerative state.

Let

```math
T_d
```

be the successful first-passage time across distance `d`.

For positive distances `a,b`, continuity requires a trajectory reaching `a+b` to cross `a` first.

The strong-Markov property then gives

```math
\boxed{
T_{a+b}
\overset{d}{=}
T_a+T_b',
}
\tag{1}
```

where `T_b'` is independent of `T_a` and distributed like a fresh passage over distance `b`.

Thus the transit-time distribution itself forms a **convolution semigroup in distance**.

This is stronger than saying only that mean delays add.

## 2. Distance behaves like the 'time' parameter of a subordinator

Because

```math
T_{d_2}\ge T_{d_1}
```

for `d_2>d_1` in the continuous-path first-passage construction, and Eq. (1) gives stationary independent increments in `d`, the family `T_d` is a subordinator in the distance coordinate.

Its Laplace transform therefore has the form

```math
\boxed{
E[e^{-sT_d}]
=e^{-d\Phi(s)},
\qquad s\ge0,
}
\tag{2}
```

where `Phi` is a Bernstein/Laplace exponent.

With a homogeneous killing probability, an additional constant killing rate can appear in the unnormalized exponent. Dividing by the DC success probability subtracts that constant, leaving the conditioned timing transform in the same convolution-semigroup form.

## 3. Lévy-Khintchine form

For a non-killed conditioned timing subordinator,

```math
\boxed{
\Phi(s)
=a s
+
\int_0^\infty
(1-e^{-st})\,\nu(dt),
}
\tag{3}
```

where

```text
a >= 0
nu(dt) >= 0
```

and `nu` is the Lévy measure satisfying the usual integrability condition.

This has a direct timing interpretation:

```text
a -> deterministic transit-time accumulation per unit distance
nu -> stochastic positive waiting-time increments per unit distance.
```

No drift-diffusion equation has been assumed yet.

## 4. Every finite cumulant is linear in distance

From Eq. (2),

```math
\ln E[e^{-sT_d}]
=-d\Phi(s).
```

If the required derivatives exist at `s=0`, the transit-time cumulants satisfy

```math
\boxed{
\kappa_n[T_d]
=(-1)^{n+1}
d\,\Phi^{(n)}(0).
}
\tag{4}
```

Therefore

```math
\boxed{
\kappa_n[T_d]\propto d
}
\tag{5}
```

for **every finite cumulant**.

This means spatial homogeneity predicts much more than a linear mean transit time.

It predicts linear growth with distance of

```text
mean
variance
third cumulant
fourth cumulant
and every higher finite cumulant.
```

## 5. Sign constraint on higher cumulants

Because `Phi` is a Bernstein function,

```math
(-1)^{n-1}\Phi^{(n)}(s)\ge0
```

for `n>=1` wherever the derivatives exist.

Equation (4) therefore implies

```math
\boxed{
\kappa_n[T_d]\ge0
}
\tag{6}
```

for all finite cumulants of the homogeneous scalar regenerative first-passage timing distribution.

For `n>=2`, Eq. (3) makes the result especially transparent:

```math
\boxed{
\kappa_n[T_d]
=d\int_0^\infty t^n\nu(dt)

\tag{7}
```

Thus, for example, a reproducibly **negative third transit-time cumulant** is incompatible with this scalar homogeneous regenerative first-passage picture.

Since every raw cumulant is proportional to `d`, standardized cumulants obey simple power laws.

Let

```math

\frac{\kappa_n(d)}
```

```math
\boxed{

```


This is a spatial central-limit trend generated by independent regenerative increments.

A homogeneous scalar transport region should become **relatively more Gaussian in its transit-time statistics as propagation distance increases**, provided the relevant moments remain finite.
