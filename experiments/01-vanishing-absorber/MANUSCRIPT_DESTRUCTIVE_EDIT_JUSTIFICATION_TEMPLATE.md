# Destructive Manuscript Edit Justification Template

Copy this file to `MANUSCRIPT_DESTRUCTIVE_EDIT_JUSTIFICATION.md` **only** when the current user has explicitly requested a large manuscript compression or restructuring.

```text
USER_EXPLICITLY_REQUESTED_LARGE_REWRITE: true
USER_REQUEST_QUOTE: <verbatim current-user instruction authorizing compression/restructuring>
```

Then document:

- why the large rewrite is necessary;
- every section/subsection intentionally removed;
- references/equations/tables intentionally removed;
- preservation report against the current canonical source.

Do not create the active justification file for ordinary revision, hardening, integration, reviewer-response, or scientific-correction work. Do not invent or paraphrase the user quote.
