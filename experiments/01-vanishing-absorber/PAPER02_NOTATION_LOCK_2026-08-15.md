# Paper 02 — Notation and Sign Lock

**Date:** 2026-08-15  
**Status:** **MANDATORY FOR MANUSCRIPT / FIGURE WORK**

This file freezes the notation used by the Paper-02 manuscript track. Do not change signs or symbol meanings opportunistically during drafting.

## 1. Coordinate

```math
0\le z\le L
```

with

- `z=0`: upstream / illuminated-side coordinate origin used by the numerical optical kernels;
- `z=L`: collecting electrode in the planar model;
- positive carrier drift is toward increasing `z`.

A localized device-level nuisance region is denoted

```math
R\subset[0,L].
```

For the conditional collector-side stress,

```math
R=[z_d,L].
```

---

## 2. Fourier convention

Use

```math
e^{-i\omega t}.
```

Do not switch to `e^{+i omega t}` inside the manuscript.

With this convention, the homogeneous no-recombination drift-diffusion spatial exponent obeys

```math
\boxed{D\gamma^2+w\gamma=-i\omega.}
```

With recombination,

```math
\boxed{D\gamma^2+w\gamma=\kappa-i\omega.}
```

---

## 3. Point-source terminal response

Use

```math
H(z,\omega)
```

for the complex terminal-current transfer generated by a point source at depth `z`.

For a planar weighting potential and deterministic downstream velocity `v(z)`, microscopic `D=0`, `kappa=0`,

```math
\boxed{
\frac{\partial H}{\partial z}
=-\frac1L+\frac{i\omega}{v(z)}H,
\qquad H(L,\omega)=0.
}
```

---

## 4. Optical kernels and measured channels

Use

```math
g_m(z)
```

for the normalized calibrated generation kernel of spectral channel `m`:

```math
\int_0^L g_m(z)dz=1.
```

Measured channel:

```math
\boxed{
J_m(\omega)=\int_0^L g_m(z)H(z,\omega)dz.
}
```

Do not call the kernel mean itself the “generation depth” without qualification. Use

```math
\bar z_m=\int z g_m(z)dz
```

and call it the **mean generation depth**.

Remote-region overlap:

```math
\boxed{
p_{m,R}=\int_Rg_m(z)dz.}
```

## 5. Calibrated one-mode inverse

Use `r` for the exponent that appears in the forward one-mode basis of the increasing-`z` coordinate.

Stable kernel basis:

```math
F_m(r)
=\int g_m(z)
\frac{e^{r(z-z_{\rm ref})}-1}{r}
\,dz,
```

with the continuous limit

```math
F_m(0)=\int g_m(z)(z-z_{\rm ref})dz.
```

One-mode fit:

```math
\boxed{J_m=C+K F_m(r).}
```

The physical homogeneous transport exponent used in the drift-diffusion law is

```math
\boxed{\gamma=-r.}
```

Do not use `r` and `gamma` interchangeably.

---

## 6. Uniform point-source multiplier

For equally spaced source coordinates separated by `h`, use

```math
q=e^{-\gamma h}=e^{rh}.
```

Thus

```math
\boxed{
\gamma=-\frac{\log q}{h},
\qquad
r=\frac{\log q}{h}.
}
```

Any branch statement must be explicit. Paper 02 should avoid branch-heavy discussion unless needed; the numerical regime uses the continuously tracked physical branch.

## 7. Low-frequency expansion

Use

```math
\delta\gamma(\omega)
=\gamma(\omega)-\gamma_0
=-ia_1\omega+a_2\omega^2+ia_3\omega^3+O(\omega^4).
```

For homogeneous drift-diffusion-recombination,

```math
V_*=w+2D\gamma_0,
```

and

```math
\delta\gamma_{\rm DD}
=-\frac{i\omega}{V_*}
+\frac{D\omega^2}{V_*^3}
+\frac{2iD^2\omega^3}{V_*^5}
+O(\omega^4).
```

Therefore

```math
a_1=1/V_*,
\qquad
a_2=D/V_*^3,
```

and the local effective diffusion is

```math
\boxed{D_{\rm eff}=a_2/a_1^3.}
```

## 8. Microscopic versus apparent/effective diffusion

Reserve

```math
D_{\rm micro}
```

for the diffusion coefficient present in the **forward physical truth** when contrast is important.

Use

```math
D_{\rm eff}
```

for the diffusion coefficient obtained by fitting the homogeneous model to a heterogeneous response.

In the central counterexample,

```math
\boxed{D_{\rm micro}=0,
\qquad D_{\rm eff}>0.}
```

Do not call `D_eff` the measured diffusion coefficient without the word **effective**, **apparent**, or explicit model qualification.

## 9. Leakage and bias

True response decomposition:

```math
H=H_0+\delta H.
```

Channel leakage vector:

```math
\boxed{E_m=\int_Rg_m(z)\delta H(z)dz.}
```

Use

```math
\mathbf E
```

for the stacked channel discrepancy.

Calibrated one-mode model:

```math
\mathbf f(C,K,r)
=C\mathbf 1+K\mathbf F(r).
```

After profiling `C,K`, root sensitivity:

```math
\mathbf h=K\mathbf F_r,
```

```math
\mathbf h_\perp=(I-P_X)\mathbf h.
```

First-order root bias:

```math
\boxed{
\delta r
=\frac{\mathbf h_\perp^\dagger W\mathbf E}
{\mathbf h_\perp^\dagger W\mathbf h_\perp}.
}
```

Since `gamma=-r`,

```math
\boxed{\delta\gamma=-\delta r.}
```

## 10. Statistical rejection

Use

```math
\mathbf x
```

for the real-stacked multi-frequency recovered-root vector and

```math
\mathbf m(\mathbf p)
```

for the homogeneous transport model prediction.

Use

```math
C_\gamma
```

for root covariance.

Profiled test statistic:

```math
\boxed{
T=\min_{\mathbf p}
[\mathbf x-\mathbf m(\mathbf p)]^T
C_\gamma^{-1}
[\mathbf x-\mathbf m(\mathbf p)].
}
```

Alternative noncentrality:

```math
\boxed{\Lambda=\mathbf d^TQ_\perp\mathbf d.}
```

Reserve `S` or `SNR` for the explicitly defined RMS-channel SNR in the theoretical statistical example. Do not conflate it with lock-in voltage SNR, power SNR, or the earlier rank-test SNR convention.

## 12. Language lock

Use:

```text
apparent diffusion
effective homogeneous diffusion
material attribution
finite generation kernel
remote-region overlap
deterministic velocity heterogeneity
model-manifold residual
covariance-weighted rejection
```

Avoid using “false diffusion” in the title or abstract unless the context makes clear that the diffusion is false **as a microscopic material attribution**, not that the fitted parameter is algebraically invalid.

The fitted `D_eff` is a legitimate parameter of the wrong effective model; the error is interpreting it as `D_micro`.
