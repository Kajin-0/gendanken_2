# HgCdTe Four-Color Shockley-Ramo Closure — Corrected Gradient Worked Prediction

**Date:** 2026-08-10  
**Status:** **CONDITIONAL / CHECKED** high-Peclet theory worked example; uses real graded-HgCdTe optical kernels and a reduced transport sensitivity model; not a calibrated device forecast and no novelty claim

## 1. Why a new HgCdTe worked example was required

The first three-color HgCdTe material prediction mixed two issues:

```text
arrival/first-passage response versus terminal Shockley-Ramo current
and
bulk transport curvature versus a reflecting entrance boundary.
```

A matched finite-boundary control showed that most of the earlier `~0.1-1 deg` three-color phase curvature was generated by the boundary rather than by the modest bulk drift gradient.

That interpretation is superseded.

The corrected worked example therefore uses

```text
raw planar Shockley-Ramo current,
no upstream reflecting boundary,
four equally spaced mean generation depths,
and the four-color first-difference closure.
```

This isolates the theorem actually intended for a measurable terminal current.

## 2. Deliberately simple graded HgCdTe

Use

```text
T = 300 K
L = 7.6 um
x(0) = 0.55
x(L) = 0.32
```

with a linear composition profile.

The bandgap is the Hansen-Schmit-Casselman relation used throughout the repository.

Absorption uses the Moazzami above-gap empirical model and Beer-Lambert generation.

The purpose is not to reproduce a named device.

It is to ask whether the corrected four-color theorem produces a resolvable, internally self-consistent transport signal in one physically recognizable graded-HgCdTe stress.

## 3. Choose four colors by internal mean generation depth

The four-color theorem uses equal spacing in the **internal source coordinate**, not equal wavelength spacing.

Choose

```math
\boxed{
\mu_z=(2.5,3.0,3.5,4.0)\ \mu m.
}
```

Solving the Hansen/Moazzami kernels gives approximately

```text
2.5 um -> 2.134651 um
3.0 um -> 2.215042 um
3.5 um -> 2.301173 um

```

The modeled absorbed fractions are approximately

```text
0.999985
```

All four channels are therefore strongly absorbing in this explicit example.

The generation standard deviations are all close to

```text
~0.79 um,
```

but are not exactly identical.  Thus the real source-shape evolution is retained rather than artificially setting each kernel to a delta function.

## 5. Correct terminal-current observable

For a carrier generated at `z`, deterministic downstream motion gives the planar Shockley-Ramo current transform, up to a common complex prefactor,

```math
\boxed{
J(z,\omega)
=\int_z^L
\exp\left[
-i\omega\int_z^x\frac{du}{v(u)}
\right]dx.
}
\tag{1}
```

The measured spectral channel in the ideal theory is then

```math
\boxed{
J_\lambda(\omega)
=\int p_\lambda(z)J(z,\omega)dz.
}
\tag{2}
```

Use the logarithmic four-color closure

```math
\boxed{
\mathcal C_4
=2\ln(J_2-J_1)
-\ln(J_1-J_0)
-\ln(J_3-J_2).
}
\tag{3}
```

For homogeneous one-carrier propagation and rigid source translation,

```math
\mathcal C_4=0
```

exactly.

## 6. Optical-shape false-positive reference

To isolate the effect of the velocity gradient, propagate the **same four real HgCdTe generation kernels** through one homogeneous deterministic law with constant velocity equal to the path-harmonic mean of the graded profile.

This reference contains

```text
exactly the same wavelength-dependent source means,
widths,
asymmetries,
and absorption fractions
```

but no spatial transport gradient.

Its nonzero `C4` is therefore the optical source-shape-evolution floor for this explicit high-Peclet comparison.

This is the correct control for the question being asked.

## 8. Independent analytic cross-check

The low-RF slowness-gradient theorem predicts

```math
\mathcal C_4
=-i\omega h^2
\left[
2q'(z_c)-(L-z_c)q''(z_c)
\right]
+O(\omega h^4,\omega^2),
```

where

```math
q=1/v,
```

```text
h = 0.5 um
zc = 3.25 um.
```

For the explicit HgCdTe velocity profile, the point-source theorem gives at `100 MHz`

```math
\boxed{
\arg \mathcal C_{4,grad}
\text{ scale}\approx-0.01254^\circ.
}
```

The full finite-width optical calculation gives a gradient-sensitive excess

```math
\boxed{-0.01238^\circ.}
```

at the same RF frequency.

The agreement is close despite the real generation kernels having approximately `0.79 um` width.

This is a strong internal consistency check between

```text
analytic point-source slowness-gradient theory
and
full finite-width graded-HgCdTe optical averaging.
```

## 9. Why the corrected signal is smaller than the old one

The earlier three-color model produced phase curvature around

```text
0.1-1 degree
```

and initially attributed it to the bulk drift gradient.

A matched finite-slab calculation showed that the reflecting entrance boundary generated nearly all of that curvature.

The corrected boundary-free raw-Ramo calculation gives a gradient scale closer to

```text
~0.012 deg at 100 MHz
~0.060 deg at 500 MHz
~0.11 deg at 1 GHz
```

for this particular stress.

That reduction is scientifically necessary.

The smaller number is the one consistent with the observable-corrected and boundary-controlled gedanken experiment.

---

## 10. Optical correction is not negligible but is structured

At `100 MHz`, the homogeneous optical floor is about

```math
+0.00246^\circ,
```

roughly one-fifth of the magnitude of the gradient-sensitive excess.

So this is **not** an optics-free experiment.

However, the separate optical-error theorem predicts that the leading source-width contamination in mean-depth coordinates depends only on the third discrete difference

```math
\Delta^3\sigma_z^2.
```

The four real HgCdTe kernels have very similar widths, which is why the optical term remains appreciably smaller than the transport-gradient term in this explicit quartet.

A real test should calculate the full optical kernels rather than merely subtract a nominal width correction.

## 11. What would falsify this worked model

Within the stated high-Peclet one-carrier geometry, the model predicts:

1. the four-color phase closure should be approximately linear in RF at sufficiently low frequency;
2. its sign should agree with the slowness-gradient combination in the analytic theorem;
3. after replacing the graded velocity by its homogeneous harmonic mean, the residual should collapse to the independently calculable optical source-shape floor;
4. the inferred propagation exponent from current first differences should produce one RF-independent real `D,w` pair only if ordinary drift-diffusion remains an adequate stochastic extension.

Failure can therefore be classified rather than absorbed into a fitted velocity curve.

## 12. Important limitations

This worked prediction omits or idealizes

```text
finite entrance boundary,
full stochastic drift-diffusion propagation,
recombination,
electron-hole coexistence,
nonuniform weighting field,
contacts/depletion-region current,
multiple carrier populations,
trapping/nonlocal transport,
reflection/interference optics,
and actual measurement covariance.
```

Those omissions are intentional.

The purpose is a simple falsifiable gedanken baseline whose assumptions can be added and tested one at a time.
