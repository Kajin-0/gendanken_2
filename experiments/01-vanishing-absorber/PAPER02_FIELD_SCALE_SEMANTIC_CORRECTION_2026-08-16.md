# Paper 02 field-scale semantic correction — 2026-08-16

**Status:** CHECKED ANALYTICAL CORRECTION / MANUSCRIPT WORDING BLOCKER

**Consequence:** Do not canonicalize a manuscript revision that describes `space_charge_drop_v = 0.05 V` as a literal extra `0.05 V` terminal drop confined to the last `3 um` or calls `0.05 V / 3 um = 166.7 V/cm` the average added field.

## Source-model definition

The central full-contact planar-depletion stress in

```text
numerics/realistic_geometry_closure_stress.py
```

uses

```text
L = 7.6 um
V_bias = 0.30 V
W_d = 3.0 um
space_charge_drop_v = Delta = 0.05 V
```

and, in the collector-side region `z >= L-W_d`, the finite-difference Poisson right-hand side is

```math
V''(z)=\frac{2\Delta}{W_d^2}.
```

The terminal potentials remain fixed at

```math
V(0)=0,\qquad V(L)=V_{\rm bias}.
```

Therefore `Delta` is a curvature parameter. It is not an independently added terminal voltage.

## Exact planar solution

Let `a=L-W_d`. For the full-contact planar case the one-dimensional continuum solution is

```math
V(z)=Az,\qquad 0\le z<a,
```

and

```math
V(z)=Az+\frac{\Delta}{W_d^2}(z-a)^2,
\qquad a\le z\le L,
```

with

```math
A=\frac{V_{\rm bias}-\Delta}{L}.
```

For the manuscript parameters,

```text
A = 0.03289473684 V/um
```

so the total electric-field magnitude in the planar solution changes from approximately

```text
328.95 V/cm at the upstream edge of the curved region
```

to

```text
662.28 V/cm at the collecting boundary.
```

The average field across the last `3 um` is

```text
495.61 V/cm.
```

The uniform `0.30 V / 7.6 um` field would be

```text
394.74 V/cm.
```

Thus the **mean increase relative to the uniform-bias profile** over the last `3 um` is approximately

```text
100.88 V/cm,
```

and the actual increase in potential drop across that region relative to the uniform profile is

```text
0.030263 V,
```

not `0.05 V`.

Meanwhile,

```math
\frac{\Delta}{W_d}=166.67\ \mathrm{V/cm}
```

is a useful **characteristic curvature-field scale**, and

```math
\frac{2\Delta}{W_d}=333.33\ \mathrm{V/cm}
```

is the field swing generated by the quadratic term across the curved region before the global fixed-bias redistribution is accounted for.

## Scientific effect on the manuscript

The earlier physical-scale comparison is not invalidated. In fact, the exact mean field increment of about `100.9 V/cm` remains within the independently reported `~100--200 V/cm` composition-gradient field scale used only as a plausibility comparison.

The necessary correction is semantic and quantitative:

### Do not write

> an added electrostatic drop of 0.05 V across a 3.0 um collector-side region, corresponding to an average added field of 166.7 V/cm

### Preferred wording

> a collector-side Poisson-curvature parameter of 0.05 V over a 3.0 um region, corresponding to a characteristic curvature-field scale Delta/W_d = 166.7 V/cm. With the terminal bias fixed at 0.30 V, the exact planar solution redistributes the field from approximately 328.9 to 662.3 V/cm across that region; its mean field exceeds the uniform-bias value by approximately 100.9 V/cm.

This wording separates the code parameter from the physical field actually solved.
